Before you ask

Does this replace checking with the Planning Authority?

No. This is a reference and verification tool — it gets you to the right clause fast, but the local Planning Authority (or MCGM, for Mumbai) has the final word, and some authorities apply modified provisions on top of the base text.

Do I need a paid Claude plan?

No. It works on a free Claude account — just enable Code execution in Settings → Capabilities. Heavy back‑to‑back usage in one sitting may hit Claude's own free‑tier daily limit, which is a Claude account limit, not something this tool controls.

What happens when UDCPR or DCPR‑2034 gets amended?

For amendment‑prone figures — FSI, premium charges, TDR rates — it checks a live source before answering, so you're not relying solely on the packaged snapshot date.

Can I use it for both a Pune project and a Mumbai project?

Yes — that's the point of bundling both regulation sets. It identifies which one applies to your question and answers from that text only.

Is this official or affiliated with the government?

No. It's an independent reference tool built from the publicly published UDCPR and DCPR‑2034 regulation text, not a government product.
